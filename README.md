# Flockjay Frontend Take-Home

## The brief

Jordan Ellis is an account executive with 50 deals in flight. It's Monday morning. Jordan has coffee, thirty minutes before the first call, and one question: **what do I do today?**

Build the view Jordan opens to answer that.

For everything in this exercise, assume today is **Monday, July 6, 2026**.

## Setup

```
npm install && npm run dev
```

Requires Node 18+.

## What's provided

- The dataset: [`src/data/deals.json`](src/data/deals.json) — Jordan's deals, exported straight from the CRM.
- The type: [`src/types/deal.ts`](src/types/deal.ts) — the shape of a deal.
- An [`App.tsx`](src/App.tsx) that imports the data and nothing else.

That's all. There are no components to fill in and no reference design to match.

## What you build

Your call, entirely. What to compute from the data, what to show first, what to leave out — that's the exercise.

When you're done, answer the prompts in [`NOTES.md`](NOTES.md). They're short, and they matter as much as the code.

## Rules

- Stack is locked: Vite + React + TypeScript. Design is free — plain CSS, a UI library, whatever you'd actually reach for.
- Clean and working beats ambitious and half-done.
- No requirement for tests, routing, or any particular pattern. What you invest your time in is part of the signal.
- AI tools are allowed but you should own every line you submit.
